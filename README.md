# Villanueva Nautical Services · web

Web estática bilingüe (ES/EN) publicada en GitHub Pages.

- `python3 prep_fotos.py` (necesita Pillow): fotos de `src/fotos` y `src/antes-despues` a `img/`.
- `python3 build.py`: genera `index.html`, `es/index.html` y `en/index.html`.
- Antes y después: `src/antes-despues/<trabajo>/antes.jpg`, `proceso.jpg`, `despues.jpg` + `info.json` con `titulo_es`, `titulo_en`, `texto_es`, `texto_en`.
